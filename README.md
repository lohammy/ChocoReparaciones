🔧 Choco Reparaciones 🔧
¡Bienvenidos a Choco Reparaciones! 📱⚡ Nuestro proyecto es una plataforma integral de gestión para talleres de reparación de telefonos celulares. Los usuarios pueden gestionar inventarios, controlar reparaciones, y llevar un seguimiento completo desde el ingreso del dispositivo hasta su entrega final.

🌟 Funcionalidades Principales:
🔧 Para Técnicos:

Gestión de Reparaciones 📋 Los técnicos pueden crear, modificar y dar seguimiento a las reparaciones de dispositivos, desde el diagnóstico hasta la finalización.
Control de Inventario 📦 Acceso completo al inventario de repuestos con control de stock en tiempo real.
Asignación de Productos 🔌 Pueden asignar repuestos específicos a cada reparación y actualizar automáticamente el inventario.

💰 Para Cajeros:

Procesamiento de Entregas ✅ Gestionar la entrega de dispositivos reparados a los clientes.
Gestión de Reparaciones 📱 Visualizar el estado de las reparaciones.
Control de Estados 🎯 Actualizar estados de reparación (Pendiente → En Proceso → Completada → Entregada).

🛠️ Para Administradores:

Gestión de Usuarios 👥 Administrar usuarios del sistema y asignar roles (Admin, Técnico, Cajero) 🔐.
Control Total de Inventario 📊 Agregar, editar y eliminar productos del catálogo de repuestos 🛒.
Supervisión de Reparaciones 📈 Acceso completo a todas las reparaciones y métricas del taller 📋.
Gestión de Productos ➕ Crear nuevos productos y mantener actualizado el catálogo de repuestos.

🎨 Características del Sistema:

Diseño Moderno 🌟 Interfaz elegante con tema dorado y diseño responsivo para móviles y tablets 📱💻.
Inventario Visual 🎯 Catálogo de productos con tarjetas modernas y información detallada de stock.
Tablas Inteligentes 📊 Listas de reparaciones con filtros avanzados y estados visuales en tiempo real.
Perfil de Usuario 👤 Sistema personalizado que muestra información del usuario y opciones de cuenta.

🛠️ Tecnologías Utilizadas:

Frontend: Blazor Server con .NET 10, HTML5, CSS3, Bootstrap 5.3 y Bootswatch Flatly 💻
Backend: C# con Entity Framework Core 🖥️
Base de Datos: SQL Server / Azure SQL Database 🗄️
Autenticación: ASP.NET Core Identity 🔐
UI Framework: Bootstrap con tema Flatly personalizado 🎨
Iconografía: Bootstrap Icons 🎯

🚀 Instalación Local:
Pre-requisitos:

.NET 9.0 SDK
SQL Server Express o SQL Server
Visual Studio 2022

Pasos:

Clonar el repositorio
Configurar connection string en appsettings.json
Ejecutar dotnet ef database update
Ejecutar dotnet run
